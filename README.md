# Pokémon Ga-Ole Console Application

A console-based Java implementation of the Pokémon Ga-Ole arcade game developed as part of a university Object-Oriented Programming assignment.

## Features

- Battle against randomly selected Pokémon
- Collect and manage Pokémon
- Turn-based battle system
- Save and load game data
- Text-based user interface
- File handling for persistent game data

## Technologies Used

- Java
- Eclipse IDE
- Object-Oriented Programming (OOP)
- File I/O

## Project Structure

```
Pokemon-GaOle/
├── src/            # Java source files
├── data/           # Game data files
├── .project
├── .classpath
├── README.md
└── .gitignore
```

## Requirements

- Java JDK 17 (or the version required by your course)
- Eclipse IDE (recommended)

## How to Run

1. Clone this repository:
   ```
   git clone https://github.com/yourusername/pokemon-gaole.git
   ```

2. Open Eclipse.

3. Import the project:
   - File → Import
   - Existing Projects into Workspace
   - Select the cloned folder.

4. Run the `Main.java` file.
